# Cockpit Buraliste

Site de présentation de Cockpit Buraliste, le copilote de gestion conçu par un buraliste, pour les buralistes.

Adresse : https://cockpit-buraliste.fr (site statique publié par GitHub Pages).

Éditeur : SNC NAILI ET CIE. Contact : contact@cockpit-buraliste.fr. Voir `mentions-legales.html`.

`cockpit.html` : l’espace buraliste en version test (bouton « Se connecter » de l’en-tête). Compte de démonstration du tabac « Le Balto », données d’exemple, page non indexée. Les exports Excel et PDF utilisent les bibliothèques de `js/` (licences dans `js/LICENCES-exports.txt`).
